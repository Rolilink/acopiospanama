# Código de conducta

Este proyecto nace para ayudar a personas afectadas por un desastre. Esperamos de todos, en issues, PRs,
discusiones y cualquier espacio del proyecto:

- Trato respetuoso, paciente y amable, sin importar experiencia, origen, género, edad, discapacidad,
  religión, orientación ni ideas políticas.
- Críticas al trabajo, nunca a las personas.
- Cuidado con los datos de terceros: no publiques información personal de nadie.
- Nada de acoso, insultos, contenido sexual, amenazas ni uso del proyecto para promoción política,
  comercial o religiosa.

Quienes mantienen el proyecto pueden editar o eliminar contribuciones y bloquear a quien incumpla estas
normas. Para reportar un problema de conducta, escribe en privado a las personas mantenedoras (ver
SECURITY.md para el canal privado de GitHub).

Inspirado en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
